# TechSpace – Technology Blog Application

TechSpace is a responsive technology blog application developed using HTML5, CSS3 and Vanilla JavaScript.

The platform allows users to register, log in, create technology articles, save drafts, publish content and manage their articles through a personal dashboard.

## Features

- Responsive homepage
- User registration and login
- Personal user dashboard
- Create and publish articles
- Save articles as drafts
- Edit and delete articles
- Dynamic article display
- Local storage data management
- Mobile-friendly navigation

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Browser Local Storage

## Project Pages

1. Home

## How to Run

1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` in your browser.
4. Register a new account.
5. Log in to access your dashboard.
6. Create, edit and publish articles.
